05 / Para o responsável pelo site

Publique pelo celular.
Toque por toque.

Os preços e horários acima já estão atualizados neste arquivo. Para as mudanças aparecerem no link que seus clientes acessam, é necessário publicar o arquivo atualizado. Se você tiver a foto do corte salva na galeria do celular, pode colocá-la no site antes de baixar o arquivo.

1. Coloque suas fotos e baixe o site

Toque em um espaço abaixo e escolha uma imagem da galeria do celular. A primeira foto também substitui a imagem principal da página.

Escolha aqui a foto enviada para “Foto principal / corte”. A imagem é reduzida para facilitar o envio. Antes de baixar, confira se apareceu na galeria acima.

As fotos escolhidas ficam neste arquivo baixado. Só escolher uma foto nesta tela não altera um site já publicado: publique o novo index.html seguindo os passos ao lado.

2. Publique grátis no GitHub Pages

  1. No celular, abra github.com/signup e crie ou acesse sua conta.
  2. Toque em + e depois em New repository. Dê um nome simples, por exemplo sam-barbearia, escolha Public e toque em Create repository.
  3. Dentro do repositório, toque em Add file → Upload files. Selecione em Downloads o index.html que você baixou acima. Toque em Commit changes.
  4. Abra Settings → Pages. Em Build and deployment, escolha Deploy from a branch; selecione main e /(root); toque em Save. Se não encontrar “Settings” no celular, ative Site para computador no menu do navegador.
  5. Aguarde alguns minutos e volte a Settings → Pages para tocar em Visit site. Seu link terá o formato https://usuario.github.io/sam-barbearia/. Abra o link e confira preços, horários e fotos.
  6. Para atualizar depois, envie outro arquivo com o mesmo nome index.html ao mesmo repositório e confirme a substituição. O link continua o mesmo.

Já tem um site em outra plataforma? Envie o index.html atualizado pelo painel dessa hospedagem, no lugar do arquivo antigo. Baixar o arquivo, por si só, não publica nada.

Digite seu usuário acima para visualizar o formato do link. O link só funcionará após você publicar e ativar o GitHub Pages.
